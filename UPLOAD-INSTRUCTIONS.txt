TPA SEARCH OPPORTUNITY ANALYZER — GITHUB UPLOAD STEPS

1. Go to GitHub and click the + icon in the upper-right corner.
2. Click New repository.
3. Name the repository: tpa-search-opportunity-analyzer
4. Choose Private or Public.
5. Click Create repository.
6. Inside the repository, click Add file > Upload files.
7. Unzip the downloaded project folder first.
8. Drag every file INSIDE the folder into GitHub. Do not upload the ZIP itself.
9. Confirm index.html is visible at the main repository level.
10. Enter the commit message: Initial TPA analyzer build
11. Click Commit changes.
12. Open Settings > Pages.
13. Under Build and deployment, choose Deploy from a branch.
14. Select branch: main
15. Select folder: / (root)
16. Click Save.
17. Wait a few minutes and return to Settings > Pages for the live website link.

EXPECTED TOP-LEVEL FILES
- index.html
- styles.css
- app.js
- README.md
- UPLOAD-INSTRUCTIONS.txt
- sample-search-term-report.csv
- sample-current-target-report.csv
- .nojekyll

IMPORTANT
- Upload the contents of the folder, not the ZIP file.
- Do not place index.html inside an extra folder.
- The app is designed for GitHub Pages and does not need a build command.

MULTIPLE REPORT UPLOADS
- The main Search Term uploader accepts up to 20 CSV/XLSX reports.
- The optional Current Keyword / Target uploader accepts up to 20 CSV/XLSX reports.
- Select multiple files at once, or upload more in later selections.
- Use Clear Search Term reports or Clear optional reports to reset either uploader.
