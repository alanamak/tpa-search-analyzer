Quick Start Guide

  1. Export your TPA Search Term Reports from Roundel. Include Campaign Name, Media Name, Keyword, Spend, Sales, Orders, Units, Clicks, Impressions, and Week or Month. You can combine up to 20 reports.
  2. Add your brand terms. Branded shopper searches will be excluded from new-target and negative recommendations.
  3. Choose the reporting period. Use the latest week, latest month, a specific period, or all uploaded periods.
  4. Select the brand objective. Each goal uses a different non-branded benchmark and primary sorting metric.
  5. Use AUTO or MANUAL. Auto loads recommended guardrails. Manual lets you use fixed ROAS/CVR goals or benchmark-relative goals.
  6. Start analyzing. Upload up to 20 Search Term reports and up to 20 optional Current Keyword / Target reports. Every result stays separated by Campaign Name and Media Name / Line Item, even when the same keyword appears elsewhere. The Excel download keeps Opportunity Keywords on the first tab and Inefficiencies on the second tab.

Campaign + Line-Item Separation

The analyzer calculates performance separately for each Campaign Name + Media Name / Line Item + stemmed search term.

The same keyword may appear on multiple rows when it performs in Tier 1, Tier 2, Tier 3, Branded, or another line item. This is intentional so you can see exactly where to add, increase, decrease, or negative target it.

How Benchmark Multipliers Work

Required threshold = non-branded benchmark × multiplier.

Example: If non-branded ROAS is 1.50x, a 115% opportunity threshold becomes 1.73x.

Benchmarks are recalculated from non-branded totals in the selected period. ROAS and CVR are recalculated from summed performance, not averaged row values.

For Maximize Revenue inefficiencies, 50% means half of the benchmark. If non-branded Order CVR is 20%, the inefficiency ceiling is 10%. Terms at or below 10% qualify for review after meeting the minimum-click threshold.
